# Cloud Sync illustrations

Empty-state artwork shown when no synced folders are configured yet.

- `sync-empty-dark.png` / `sync-empty-light.png` — per-theme pair, 300x200,
  edge-feathered so they blend into the Aura `bg` surface. Passed to
  `aura.EmptyState(image=(light, dark))`; CTkImage switches them with the theme.

Provenance: AI-generated (Krea-2-Turbo via the AIQuick image worker,
2026-08-16), prompted in the Aura design-system palette (deep blue-black /
pale light, accent #5b86f7), then Lanczos-downscaled and alpha-feathered with
Pillow. Licensed with the app (Apache-2.0).
